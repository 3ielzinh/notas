📄 Importar Nota Técnica (PDF)

ℹ️ Como funciona

  1. Upload: Envie um arquivo PDF de nota técnica
  2. Extração: O sistema extrai automaticamente:
    • Nome da nota (ex: "Nota Técnica 123/2024")
    • Ano da nota
    • Todo o conteúdo textual
  3. Anonimização: Identifica e remove dados sensíveis:
    • 🔢 SIAPE (matrículas)
    • 👤 Nomes de pessoas
    • 📋 CPFs
  4. Armazenamento: Salva versão anonimizada no banco de dados

⚠️ Importante

  • Apenas arquivos .PDF são aceitos
  • O sistema compara com {{ terms_count }} termos cadastrados
  • PDFs duplicados (mesmo hash) são automaticamente rejeitados
  • O texto original é preservado no banco para auditoria
